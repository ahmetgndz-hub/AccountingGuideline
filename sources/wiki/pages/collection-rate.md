# Collection Rate

## Description

The collection rate shows performance of collection over issued vs collected invoices with in last 12 month. 

![collectionrate.jpg](/sites/Wiki/PublishingImages/Paginas/Collection%20Rate/collectionrateV2.jpg)

- Measures the % of value of total invoices issued over a given period that the mall recovers from its tenants over the same period with respect to these invoices

- Amount invoiced and recovered from clients divided by total amount invoiced to the client
- Should be calculated on an accrual basis,

  - Last twelve months period should be used for the calculation
  - Amounts invoiced over the period should be considered in the denominator
  - Only amounts recovered with regards / matched to the same invoices should be taken into the numerator

- This will only cover current leases.
