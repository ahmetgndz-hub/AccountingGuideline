# Manual Journal Entries

### Approal matrix for manual journal entries is as follows

### **Manual Journal Approval Matrix**

| **Hierarchy Level** | **Approval limit** | **Name** |
|---|---|---|
| Position 0 | 0 |  |
| Position 1 | Up to € 25k |  |
| Position 2 | More than € 25k | FD of Country |
| Position 3 | Up to € 200k | F&A Dr. of HQ (Ahmet Gündüz) |
| Position 4 | Up to € 500k | Group FD (Frank Trees) |
| Position 5 | more than € 500k | CFO (Steven Poelman) |

            

### In case position 0 and position 1 both not filled with names from country then position 0 will be used to keep 4 eyes principle in. If country provides name for both position then Chief of Accounting / Head of Accounting allowed to approve jıournals up to € 25k

### Exemptions from workflow for manual journal entries are described in [Journal Vouchers](/sites/Wiki/Paginas/Journal%20Vouchers.aspx) page.
