# C27 Valuation bookkeeping

### This is a movement control between 

### Investment property account with valuation movement code (11111 and 054) vs valuation accounts (4331X) at p&l and this must be in line. Table shows in 2 dimensions as total (el1+el2+el3 level) vs detail as full details up to line transaction level. If total line in balance, then assigned as 1 in control column and 0 if its not reconciling. Line detail has no control on this point. 

### In total line if control has not been passed (control assigned as 0) then line highlighted as orange)

### At below example first line (PLB006 + PLBP006 + MAN) in books is not in line with our expected bookkeeping and this is stemming from Q1 (can be seen at highlighted line) and result this inconsistency is GE-JV-MAN 33246
