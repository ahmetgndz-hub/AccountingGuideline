# C14 Account code level controls

### Validation at account code level contains below controls 

| **Dummy property code usage at NRI level ** | **As part of reporting at property level all income which hits to NRI should be allocated proper element2 during bookkeeping. NRI defined as ( [Net Rental Income - NRI](/sites/Wiki/Paginas/Net%20Rental%20Income%20-%20NRI.aspx) ) (PA to PG reporting group excluding PD5A (non-recurring income) and PGH (accrual releases))** |
|---|---|
| **Employee code usage in employment costs accounts ** | **Definition of employment costs are PQ salary costs as group PR7 Travel and entertainment PR8 Car costs & -allowances PR9 Other staff costs proper element6 (in line with workday) should be used at employment cost to be able to prepare P&L at employee level** |
| **all costs needs to be assigned to proper element6** | ** This shows account codes does not have element6 at all and needs to be cancelled. ** |
