# C13 Control at document code level

### Aim in this control to make analysis over document code level to see if it's in line with our policy and procedures. 

### control points are 

| **Documents not in balance ** | **each document needs to be in balance with combination of element1 + element3 level. Sometimes resulting from wrong matching or wrong bookkeeping this happens and needs to be corrected. ** |
|---|---|
| **Documents have not been posted to books yet** | **If document still in intray of coda financials this will not be affecting financials and needs to be posted or deleted from intray to make sure completeness before closing.** |
| **Documents denied during workflow but has not been taken care of yet** | **In principle if a document denied during workflow approval this needs to be further analysed or send back or confusion needs to be clarified and workflow needs to be re started** |
