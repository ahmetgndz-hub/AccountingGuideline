# C28 Document codes vs Element 4

Since 2020 there are new documents codes implemented in Coda.
From that moment there are specific document codes created for specific purposes to be used on limited elements 4.

For explanation on combinations of document codes and elements 4 see the following wiki page via the link below:

[Document codes in use](/sites/Wiki/Paginas/Document%20codes%20in%20use.aspx)

The control in this file does the following checks:

- Document code used in combination with the allowed elements 4.
- Check on old document codes (from 2019 and before) in 2020 and later.
