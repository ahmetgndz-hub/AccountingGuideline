Online Control File

All review, remediation and sign-off of the Control File should take place in the Reporting Hub. Please continue to share any questions, issues, or improvement suggestions so that we can further enhance the process.

Process Steps

**1. Timely Closing**

All closing steps should be completed within the set timelines. No open items should remain without explicit explanation and ownership. Delays must be communicated before, not after, deadlines.

**2. Clean Control File**

The online Control File must be clean at sign-off. Any remaining issues must be (i) clearly identified, (ii) properly explained, and (iii) actively remediated in the Reporting Hub. A Control File with unexplained issues will not be considered acceptable.

**3. Role of the Finance Director**

Active involvement of the Finance Director is pivotal to the process. The FD reviews and signs off on (i) completeness of the closing, (ii) accuracy of the numbers, and (iii) quality of the Control File.
