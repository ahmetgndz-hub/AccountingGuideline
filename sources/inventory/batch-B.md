# Batch B — closing instructions 2025-07 … 2026-02 (inventory)

Fetched 2026-10-09 via the Microsoft 365 connector (read-only). Raw HTML bodies kept in the
session scratch dir; converted files are in `sources/emails/`.

**Batch-wide caveat.** In every mail of this batch the closing timetable ("attached schedule",
"below schedule", "critical steps flagged below", "closing calendar") is an inline picture
(`image00x.png` / `oledata.mso`), not HTML text. The converter therefore produces no milestone
rows; the `Timetable:` line below records that, and only the dates written in the body text
are listed. Nothing was hand-edited. Converter cosmetic artefact in several files: adjacent bold
runs are glued together (e.g. `**FPR file (Financial Performance Review)Attention items**`,
`deadlineis set at**`), content is intact.

Authorship shifts inside the batch: July 2025 by Ahmet Gunduz, August–December 2025 by Egbert van
Zomeren, January–February 2026 by Sudipta Dash. The wording of the standard paragraphs changes with
the author (see "Changes vs previous mail").

## Cross-batch observations

- **Timetables are images throughout.** None of the ten mails carries the milestone table as text; the document codes / map codes / account numbers that Batch A and C tables may contain are not recoverable from this batch. If the closing-calendar page needs the 2025-07 … 2026-02 milestone rows, the images (or the Closing Checklist V2.2.xlsx of 2025-09-29) must be read separately.
- **Control-file acceptance standard oscillates with the author:** Ahmet (Jul 2025) and Sudipta (Jan–Feb 2026): "clean, or issues flagged and explained"; Egbert (Aug–Dec 2025): "clean, without exceptions … not accepted … Closing is not finalized".
- **Deliverable naming:** "FPR file (Financial Performance Review)" Jul–Dec 2025, "RMA file (Financial Performance Review)" from Jan 2026.
- **Coda closure pattern:** books closed the day after the deadline (Sat 16 Aug, Fri 19 Sep, Fri 17 Oct, [Fri 14 Nov], Tue 16 Dec, Thu 22 Jan → actually Tue 27 Jan 12:00, Fri 13 Feb, Tue 17 Mar).
- **Date typos to be corrected when deriving the calendar:** "Friday, 14 October" (Oct 2025 mail), "October books" (Nov and Dec deadlines), "12th February 2025" (Jan 2026 mail).
