# Writing off receivables

<div class="page-meta" markdown>
**Applies to:** asset and service companies · **Owner:** Group Finance · **Last reviewed:** 2026-10-08
</div>

## Rule

Multi is reluctant to write off: a written-off receivable disappears from the MAN books. Write off only when all "must" conditions are met, and only with a signed **Write-off Approval Form (WAF, 2.3-16)** signed by the Asset Manager, Country MD and FD. Write-offs above **€100.000** (individually or in aggregate) also need the Group CFO.

| Criterion | Current policy | |
|---|---|---|
| Financial condition of the tenant | Tenant deemed insolvent by court procedure or other external evidence | Must |
| Proceeding | Proceeding started against the tenant or its group, or a documented cost / benefit decision not to start one | Judgement |
| Securities | Bank guarantee, deposit, cheques and other securities fully used | Must |
| VAT | VAT prepaid on the receivable recovered from the tax authorities to the maximum extent | Must |
| Presence in the centre | Tenant has vacated the centre; while present, increase collection efforts instead | Must |
| Days outstanding | More than 720 days overdue | Indicative |

The write-off proposal is shared with HQ Group FD at every close (checklist point 4).

## How to (Coda)

| Dr | Cr | Note |
|---|---|---|
| 13113 Provision (EL8 410) | 42593 Doubtful debt provision | release the provision (43000 if the provision was booked in a previous year) |
| 42594 Write-off receivables | 13111 Trade receivables | remove the receivable |

Element 6 = tenant, external reference 3 = lease reference. Document code `JV-MANUAL` (workflow).
