This is the single place for Multi's accounting policies, month-end closing rules and system
conventions. It replaces the scattered guideline e-mails and the outdated Multi Wiki page on
SharePoint. If a rule is not here, it is not the rule.

## How to use this site

- **Looking for a rule?** Use the search box (top) or browse the [Guideline](topics/index.md) section.
- **Closing a month?** Start with the closing calendar in the Guideline section.
- **Something changed?** Every page ends with a change log naming the e-mail that introduced the change.
  The [global change log](changelog.md) lists all changes in date order.
- **Found something outdated or missing?** Tell Group Finance, or follow
  [How to update this site](how-to-update.md).

## Principles

1. **Newest instruction wins.** When an older and a newer instruction differ, the newer one applies and
   the older one is removed from the guideline (it stays archived in the source e-mails).
2. **Policy first, then system.** Each topic states the rule, then how to apply it in Coda, then the deadline.
3. **One topic, one page.** No duplication across pages. Cross-links instead.

## Open points

Items where the source material is unclear or where two instructions conflict on substance.
Group Finance decides; until then the newest instruction applies.
