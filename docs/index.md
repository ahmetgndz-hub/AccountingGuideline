This is the single place for Multi's accounting policies, month-end closing rules and Coda conventions. It replaces the Multi Wiki on SharePoint (103 pages, migrated and reorganised on 8 October 2026) and the guideline e-mails sent over time. If a rule is not here, it is not the rule.

## How to use this site

- **Looking for a rule?** Use the search box or browse the [Guideline overview](topics/index.md).
- **Closing a month?** Start with the [closing calendar](topics/closing-calendar.md), then the [closing checklist](topics/closing-checklist.md) and the [Accounting Control File](topics/control-file.md).
- **Something changed?** Every page ends with a change log naming its source. The [global change log](changelog.md) lists all changes in date order.
- **Found something outdated or missing?** Tell Group Finance, or follow [How to update this site](how-to-update.md).

## Principles

1. **Newest instruction wins.** When an older and a newer instruction differ, the newer one applies and the older one is removed from the guideline (it stays archived under `sources/`).
2. **Policy first, then system.** Each topic states the rule, then how to apply it in Coda, then the deadline.
3. **One topic, one page.** No duplication across pages; cross-links instead.
